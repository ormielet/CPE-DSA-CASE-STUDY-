# DSA-CPE (frontend)

```
html/landing-page.html   landing page: hero, module cards, case study info, team
html/stack.html          Stack (Parking Garage) page
html/queue.html          Queue (Parking Garage) page
css/landing-page.css     base styles (colors, top bar, drawer, buttons) + landing page sections
css/stack.css            Stack page styles
css/queue.css            Queue page styles
js/landing-page.js       top bar + sidebar drawer, scroll effects (loaded by all three pages)
images/                  logo, module illustrations, team/ photos
```

Open `html/landing-page.html` to start. The Stack and Queue cards (and the sidebar/top bar links) are plain links, so no JS is needed to switch between pages.

Search the project for `PLACEHOLDER` to find the spots that still need a photo or description.
